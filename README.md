# CStore — CremnityStore

Открытый каталог Android-приложений, аналог F-Droid. Каталог целиком собирается из папки
[`projects/`](./projects): каждая подпапка — это приложение с метаданными, иконкой,
скриншотами и APK-файлом.

Сайт открывается сразу каталогом: `/`

## Стек

- **Next.js 16** (App Router, React 19, Server Components)
- **Tailwind CSS 4** + собственный дизайн-система (светло-фиолетовый / чёрный)
- Иконки — `lucide-react`
- Хостинг — **Vercel**, без базы данных: всё читается из файлов репозитория

## Возможности

- Каталог с поиском по названию, пакету, разработчику и тегам
- Фильтры по категориям, сортировка (популярные / новинки / обновления / алфавит)
- Два режима отображения — сетка и список
- Страница приложения (модальное окно + прямая ссылка `/?app=slug`)
- История версий с changelog, SHA-256, разрешениями, лицензией
- Категории (`/categories`), О проекте (`/about`), документация (`/docs`)
- Публичный JSON API (`/api/apps`, `/api/apps/:slug`) и RSS (`/feed.xml`)
- Иконки, скриншоты и APK раздаются через `/projects/<slug>/...`

## Как добавить приложение

1. Скопируйте `projects/_template/` → `projects/<slug-приложения>/`
2. Заполните `app.json` (полное описание полей — страница `/docs` на сайте)
3. Положите `icon.png`, скриншоты и APK в папку приложения
4. Закоммитьте изменения — после деплоя приложение появится в каталоге

Пример заполнения: [`projects/cremnotes`](./projects/cremnotes).

> Папки, имена которых начинаются с `_` или `.`, каталог игнорирует —
> поэтому шаблон `_template` на сайте не отображается.

```jsonc
{
  "name": "CremNotes",
  "packageId": "com.cremnity.notes",
  "summary": "Короткое описание для карточки",
  "description": "Полное описание",
  "developer": "Cremnity Labs",
  "license": "GPL-3.0",
  "categories": ["Заметки"],
  "icon": "icon.png",
  "screenshots": ["screenshots/1.png"],
  "sourceCode": "https://github.com/...",
  "releases": [
    {
      "version": "1.2.0",
      "versionCode": 120,
      "date": "2026-11-03",
      "file": "cremnotes-1.2.0.apk"
    }
  ]
}
```

## Локальный запуск

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production-сборка
```

## Источник данных

- **Локально** каталог читается из папки `projects/`.
- **На Vercel** каталог читается напрямую из GitHub (`projects/*/app.json` в ветке `main`),
  поэтому новое приложение появляется на сайте сразу после пуша — без редеплоя.
  Если удалённый источник недоступен, используется сборка.
- Медиа (иконки, скриншоты, APK), которых нет рядом в сборке, проксируются
  из `raw.githubusercontent.com` тем же адресом `/projects/<slug>/...`.

## Переменные окружения (необязательные)

| Переменная              | Назначение                                                       |
| ----------------------- | ---------------------------------------------------------------- |
| `NEXT_PUBLIC_SITE_URL`  | Базовый адрес сайта для `sitemap.xml`                             |
| `CSTORE_REPO`           | Репозиторий каталога (по умолчанию `littlelegsoff-dev/Cremnoty-Store`) |
| `CSTORE_REF`            | Ветка каталога (по умолчанию `main`)                               |
| `CSTORE_RAW_BASE`       | Базовый raw-URL репозитория                                       |
| `CSTORE_REMOTE_CATALOG` | `0` — читать только локальные файлы, `1` — всегда из GitHub        |
| `CSTORE_GITHUB_TOKEN`   | Токен для приватного репозитория или обхода лимитов GitHub API     |

## Структура

```
app/                 страницы и API-роуты Next.js
components/          UI-компоненты каталога
lib/                 чтение метаданных, типы, форматирование
projects/            ← сюда добавляются приложения
  _template/         шаблон папки приложения
  cremnotes/         заполненный пример
source/              заметки по исходникам проекта
public/              статика (favicon)
```
