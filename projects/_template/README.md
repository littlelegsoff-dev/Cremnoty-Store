# Шаблон папки приложения

Скопируйте эту папку и переименуйте её в slug приложения (латиница, цифры, дефис),
например `projects/my-app/`. Папки, начинающиеся с `_`, каталог игнорирует —
этот шаблон на сайте не появится.

Структура:

```
projects/my-app/
├── app.json          обязательный файл с метаданными (или app.yml)
├── icon.png          иконка 512×512 (по умолчанию ищется icon.png)
├── screenshots/      скриншоты, перечисляются в app.json
└── my-app-1.0.0.apk  собранный APK, имя указывается в releases[].file
```

Что важно:

- `size` и `sha256` в релизах можно не указывать — размер посчитается по файлу,
  а контрольную сумму удобно получить командой `sha256sum my-app-1.0.0.apk`.
- Если APK слишком большой для репозитория, загрузите его в GitHub Releases
  и укажите полный `url` вместо `file`.
- Готовый пример с заполненными данными — `projects/cremnotes/`.
- Полная документация по полям — страница `/docs` на сайте.
